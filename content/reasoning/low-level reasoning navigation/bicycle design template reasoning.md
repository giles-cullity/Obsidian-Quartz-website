- provisional description:
	- mapping out all the possible good/best bicycle designs (rather having to choose the very best)
	- i.e. specifying every "good" bicycle design in parametric form
	- doing this because my design process for building one involves going through the options systematically, and I don't want to throw out all the work that gets done finding all the other variations I like along the way.
	- there has to be a cut-off (in overall design quality), below which I'm not going to map out any of the possible designs
	- the reasoning process for the one I actually build ("bicycle build reasoning) is going to start from the conclusions of this - start with a range of designs that I like then narrow down to my very favorite one. It won't involve duplicating all the reasoning from here
	- This isn't just part of the design process of the one I'm building. Knowing what range of designs I really like has value in itself (satisfaction of creative drive)
