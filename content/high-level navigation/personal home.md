  - provisional_description:
  	- This corresponds the the main navigation pathways I use when using the Obsidian app. That in turn corresponds to the folder structure I used to use in File Explorer, except I get to make it multi-faceted - with the "by other facets" notes at the ends of the lists, I can view my files by categories that cross-cut the main list of categories. These personal navigation paths are in contrast to the recommended navigation pathways for the public on the this website. The idea is for my website to be as close as possible to the notes I write for myself. The main difference is where you start from when navigating. Naturally, people who don't know me are going to want to see categories like "about me", "my ideas", etc, not "planning reasoning", "saved art/music", etc
  	- personal_navigation: lets people browse the notes on my website as I browse them in the desktop app - this is one of the best (and most personal) ways of showing who I am.
